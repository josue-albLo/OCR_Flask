# Instalar el proyecto

1. [Instalar la version 3.11 del sitio oficial de python](https://www.python.org/downloads/release/python-3119/)
2. Instalar virtualenv, para crear un entorno en el proyecto, con el siguiente comando ```pip install virtualenv```
3. Para **windows**, en la ruta raiz del proyecto ejecutar el siguiente comando: ```py -m venv venv```
4. Activar con el siguiente comando: ```.\venv\Scripts\activate```
5. Una vez el entorno se ha instalado, instalamos las librerias con el siguiente comando: ```pip install -r requirements.txt```
6. Ejecutar el siguiente comando para correr la aplicacion: ```py app.py```
7. Listo!!!
